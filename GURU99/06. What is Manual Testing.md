✅ **Manual Testing**

---

📌 **What is Manual Testing?**
Manual Testing is a **type of software testing** where **testers execute test cases manually**, **without using any automation tools**, to find defects in a software application.

---

### ✅ **Key Points**

* Testers act **like real users** to check if the software works as expected.
* Test scenarios are run **step by step**, observing the actual vs. expected results.
* It checks **UI, usability, functionality, and user experience**.

---

### ✅ **Where It’s Used**

* **Exploratory Testing:** When requirements are incomplete or unstable.
* **Usability Testing:** To verify the app is user-friendly.
* **Ad-hoc Testing:** To catch random bugs by using the system in unplanned ways.

---

### ✅ **Example**

A tester manually:

* Opens the login page.
* Enters valid & invalid credentials.
* Checks if correct error messages appear.
* Verifies successful login redirects to the dashboard.

---

📌 **Goal:**
Ensure the software works correctly **from the end-user’s perspective** — before automating repetitive tasks.
