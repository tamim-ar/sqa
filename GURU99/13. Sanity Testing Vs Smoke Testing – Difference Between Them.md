**Sanity Testing vs Smoke Testing — Difference**

| Aspect         | Sanity Testing                                                            | Smoke Testing                                                          |
| -------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Purpose        | Verify specific functionality or bug fixes                                | Verify basic critical functionalities                                  |
| When Conducted | After receiving a new build with minor changes or bug fixes               | After receiving a new build to check stability before detailed testing |
| Scope          | Narrow and focused on particular areas                                    | Broad and shallow, covering major features                             |
| Depth          | Deep enough to verify the particular functionality                        | Basic, superficial check                                               |
| Conducted By   | Usually testers or developers                                             | Usually testers                                                        |
| Automation     | Can be automated or manual                                                | Often manual, sometimes automated                                      |
| Result         | Determines if the specific feature is working properly to proceed further | Determines if build is stable enough for further testing               |
| Example        | Testing a fixed bug or new functionality                                  | Checking login, app launch, main menu                                  |
