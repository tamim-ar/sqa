✅ **Automation Testing**

---

📌 **What is Automation Testing?**
Automation Testing is a type of software testing where **test cases are executed automatically** using **automation tools** and **scripts**, instead of being run manually by testers.

---

### ✅ **Key Points**

* Saves **time and effort** for repetitive tasks.
* Increases **accuracy** (reduces human error).
* Supports **regression testing**, **performance testing**, and **continuous integration**.
* Requires **initial investment** in tools, framework, and scripting.

---

### ✅ **Where It’s Used**

* **Regression Testing:** Re-running old test cases after code changes.
* **Smoke & Sanity Testing:** Quick checks to see if builds are stable.
* **Performance Testing:** Simulating thousands of users.
* **Data-driven Testing:** Running the same test with multiple data sets.

---

### ✅ **Popular Tools**

* Selenium
* Cypress
* Playwright
* JUnit, TestNG
* Postman (for API automation)
* JMeter (performance)

---

### ✅ **Example**

Automate login functionality:

* Script opens browser.
* Navigates to login page.
* Enters username & password from test data.
* Clicks login.
* Verifies successful redirect to dashboard.
* Logs results automatically.

---

📌 **Goal:**
**Run tests faster, more often, and more reliably** — especially for large, complex applications.
