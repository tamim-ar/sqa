✅ **Integration Testing**

---

📌 **What is Integration Testing?**
Integration Testing is the process of testing **combined modules or components together** to verify that they work correctly when integrated.

---

### ✅ **Purpose**

* To find issues in the interaction between modules.
* Ensures data flow and communication between modules is correct.

---

### ✅ **Example**

Imagine an e-commerce app with:

* **Module A:** User Login
* **Module B:** Shopping Cart

**Integration Test:** Verify that after logging in (Module A), the user can add items to the shopping cart (Module B) and the cart shows the correct items.

---

### ✅ **Types of Integration Testing**

* **Big Bang:** Test all modules together at once.
* **Top-Down:** Start testing from top-level modules and integrate downwards.
* **Bottom-Up:** Start testing from bottom modules and integrate upwards.
* **Incremental:** Integrate and test modules one by one.
