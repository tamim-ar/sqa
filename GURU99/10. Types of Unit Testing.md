✅ **Types of Unit Testing**

---

### 1️⃣ **Manual Unit Testing**

* Developers manually test individual units by writing test code and running it without automation tools.
* Usually done in early development for quick checks.

### 2️⃣ **Automated Unit Testing**

* Unit tests are written as automated scripts using testing frameworks.
* Can be run repeatedly and integrated into CI/CD pipelines.

---

### Other Classifications Sometimes Used:

| Type                      | Description                                                             |
| ------------------------- | ----------------------------------------------------------------------- |
| **White Box Testing**     | Unit testing is mainly white-box — tests internal logic and code paths. |
| **Mock Testing**          | Use of mocks/stubs to isolate the unit from dependencies.               |
| **Parameterized Testing** | Run the same test logic with multiple input sets automatically.         |

---

### Example:

* Writing automated unit tests in JUnit or PyTest is **Automated Unit Testing**.
* Manually calling and checking a function’s output in an IDE is **Manual Unit Testing**.
