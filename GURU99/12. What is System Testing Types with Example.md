✅ **System Testing**

---

📌 **What is System Testing?**
System Testing is the process of testing a **complete and fully integrated software product** to verify that it meets the specified requirements. It validates the system’s **end-to-end functionality**, performance, security, and reliability.

---

### ✅ **Types of System Testing with Examples**

| **Type**                     | **Description**                                                  | **Example**                                                            |
| ---------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **1. Functional Testing**    | Checks if software functions according to requirements.          | Verify user login, registration, and profile update work correctly.    |
| **2. Performance Testing**   | Tests system speed, scalability, and stability under load.       | Check if the website handles 10,000 users simultaneously.              |
| **3. Security Testing**      | Checks system’s protection against unauthorized access.          | Test login with wrong credentials and attempt SQL injection.           |
| **4. Usability Testing**     | Evaluates how user-friendly and intuitive the system is.         | Ensure users can navigate easily through a shopping site.              |
| **5. Compatibility Testing** | Checks system behavior on different devices, OS, and browsers.   | Test website on Chrome, Firefox, Android, iOS, etc.                    |
| **6. Regression Testing**    | Verifies that new changes haven’t broken existing functionality. | After adding a payment feature, check if previous features still work. |
| **7. Acceptance Testing**    | Validates the system meets business needs and requirements.      | Final user tests the system to approve for release.                    |
