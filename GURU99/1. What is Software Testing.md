**📌 Software Testing**

**Software Testing** is the process of **evaluating and verifying** that a software application or system works **correctly**, **meets specified requirements**, and is **free of defects**.

In simple terms, it checks **“Does the software do what it’s supposed to do?”**

---

### ✅ **Key Goals of Software Testing**

* Find bugs and defects.
* Ensure software works as expected.
* Improve product quality.
* Verify performance, security, usability, and reliability.
* Validate that it meets business and user needs.

---

### ✅ **Basic Types**

* **Manual Testing:** Human testers execute test cases without automation tools.
* **Automation Testing:** Tests are executed automatically using scripts and tools (e.g., Selenium, JUnit).

---

### ✅ **Example**

Before launching an online banking app:

* Test login with valid/invalid credentials.
* Check money transfer feature works.
* Ensure data is encrypted.
* Verify it works on multiple devices.

---

👉 **Result:** Confident delivery of a reliable, high-quality software product!
