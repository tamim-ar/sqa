✅ **Unit Testing**

---

📌 **What is Unit Testing?**
**Unit Testing** is a **type of software testing** where **individual units/components of code** (like functions, methods, or classes) are **tested in isolation** to verify they work correctly.

---

### ✅ **Key Points**

* Smallest testable part of an application.
* Usually done by **developers** during development.
* Helps catch bugs **early**, before integration.
* Runs fast, easy to automate.

---

### ✅ **Example**

If you have a function:

```python
def add(a, b):
    return a + b
```

A unit test checks:

* `add(2, 3)` returns `5`
* `add(-1, 1)` returns `0`

---

### ✅ **Tools**

* **Java:** JUnit
* **Python:** PyTest, unittest
* **JavaScript:** Jest, Mocha

---

📌 **Goal:**
Ensure each **code unit** works **as expected**, so bigger modules work correctly when combined.
