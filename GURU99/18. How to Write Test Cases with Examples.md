# 🧪 How to Write Test Cases

## 🧩 Scenario
**Check Login Functionality**

---

## 🪜 Step 1: Define the Test Case

| **Test Case #** | **Test Case Description** |
|-----------------|----------------------------|
| 1 | Check response when valid email and password is entered |

---

## 🧮 Step 2: Identify Test Data

| **Test Case #** | **Test Case Description** | **Test Data** |
|-----------------|----------------------------|----------------|
| 1 | Check response when valid email and password is entered | Email: `guru99@email.com`<br>Password: `lNf9^Oti7^2h` |

> ⚠️ Test data must be documented carefully and may need to be created manually if not available.

---

## ⚙️ Step 3: Define Test Steps

| **Test Case #** | **Test Case Description** | **Test Steps** | **Test Data** |
|-----------------|----------------------------|----------------|----------------|
| 1 | Check response when valid email and password is entered | 1. Enter Email Address<br>2. Enter Password<br>3. Click **Sign In** | Email: `guru99@email.com`<br>Password: `lNf9^Oti7^2h` |

> 🧠 Well-documented steps help new testers execute and review test cases efficiently.

---

## 🧾 Step 4: Document Expected & Actual Results

| **Test Case #** | **Test Case Description** | **Test Data** | **Expected Result** | **Actual Result** | **Pass/Fail** |
|-----------------|----------------------------|----------------|----------------------|------------------|----------------|
| 1 | Check response when valid email and password is entered | Email: `guru99@email.com`<br>Password: `lNf9^Oti7^2h` | Login should be successful | Login was successful | ✅ Pass |

> ✅ During test execution, compare **Expected** vs **Actual** results and mark as **Pass/Fail**.

---

## 🔒 Step 5: Add Pre-Conditions and Post-Conditions

| **Pre-Condition** | **Post-Condition** |
|--------------------|--------------------|
| Browser must be installed and the website must be accessible. | Time and date of login are stored in the database. |

---

## 🧭 Summary

A good test case should include:

- Clear and concise description  
- Defined test data  
- Detailed test steps  
- Expected and actual results  
- Pre-conditions and post-conditions  

---

By following these steps, you can create effective and efficient test cases that ensure thorough testing of application functionalities.
